> 目標（Addis）：第一步先把**面內區自主調參**做好——**不誤判**，且 **bypass 越小越好**。
> 方法：引擎算出的參數**真的寫成 RecipeInfo.xml**，交給 **IP（cfaoi_ip offline-file）逐張實檢整條 CCD**，
> 數誤判 / 真缺陷 / 實際檢到的面積。工具：`tools/autotune/validate_ip.py`（在 Spark 跑）。

## 資料

- T550QVN10_TGT_G **IP04 整條**：29 張 slice（Origin000000–000028），8160 × 5000，接起來 = panel 8160 × 145000。
  - #0 含玻璃前緣（上方 ~1546 列為玻璃外）與前緣外圍；#14/#15 為兩排晶片間的間隙（含 dummy 週期帶、pad、亮帶、暗線）；

  周圍 ≈ 93，比值 ≈ 0.58；舊機台批次報告未列，**待 Addis 確認**）。其餘一律算誤判。

## 驗證過程中修掉的 IP 問題（feat/panel-roi）

1. **I8 panel 座標配方**（`docs/code_review_20260802.md`）：配方 ROI 可用整片 panel 座標，逐張依 `sliceIndex` 平移、
   與本張不相交的 zone 略過（舊行為：clamp 成 1px 條照跑 = 靜默零覆蓋）。判定：任一 zone 的 EndY > 張高 → 整份配方視為
   panel 座標（單張座標配方行為不變）。offline-file 由檔名 `Origin(\d+)` 取 sliceIndex；IOI 同樣平移。
2. **I4 texture 快取只比指標**：多 zone 共用同一 buffer、換成較高的 zone 時沿用舊 texture 高度 → 超出列被 clamp →
   **每張 y≈1914 整列 1,774 顆假暗點**（slice 0 的 zone 高 1931）。單獨跑 slice 1 = 0 顆、接著 slice 0 跑 = 67 顆 → 重現。
   修：快取鍵加入寬高；texture 建立失敗（高 > ~65000，例 `--stitch` 整片 145000 列）改退回非 texture 路徑，不再 CUDA 致命錯。

回歸（`ip/build_at`）：整條 `--verify-deterministic` bit-exact ✓；#27 參考測試（ini 預設）1 顆 ✓；
`verify_alignment` 12/12 ✓；`verify_rules_edge`（IOI/規則）4/4 ✓；`verify_coord` 5/6 —— S1B（GlobalPosX_um = 0）
**main 原版同樣失敗**，與本次無關。
