## 夜間修掉的問題（都在真資料上踩到）

| 問題 | 現象 | 修法 |
|---|---|---|
| 鏡頭暗角（中央/邊緣亮度 2.5×）| CCD 邊緣晶片紋理能量不足 → IP03 第二顆晶片判成 160–8128 | 紋理能量除以局部亮度（相對能量）|
| 除亮度後玻璃外雜訊被放大 | IOI 延伸到玻璃外 | 由亮度找玻璃範圍（前後緣、左右長邊），IOI 只留玻璃內 |
| 外圍 pattern 混進 pitch 量測 | IP09 pitch 29.3×20.89 → 門檻 0.40/1.75 | pitch 兩段式：先找晶片 → 只在晶片內重量 |
| 偏暗 CCD | IP06（亮度 9）被調到 0.47/1.59，把問題蓋掉 | 亮度健檢：< 15 不調參、告警；< 全片中位數 × 0.5 照調、告警 |
| 外圍被當晶片 | IP01 前緣外圍（1632–7424）→ 2,843 假點、整片門檻 0.40/2.41 | 晶片判定：填滿率 ≥ 0.8 且能量 ≥ 最強區域一半；**每顆晶片各自校準** |
| IOI 併成一大塊 | 弱週期合併把 IP01 整條變一個 IOI | IOI 改幾何規則：前緣、後緣、列間、左右外圍、同列晶片間 |
| 晶片邊第一欄 | IP09/IP01 左緣晶片暗門檻 0.55（限制點全在 x0+53）| 晶片內側邊往內縮 1 pitch（那圈在 IOI）→ 0.630 |
| 窄框細修 | IP01 細修取到空欄崩潰 | 窄框用整個框寬 |
