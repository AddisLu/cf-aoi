CF-AOI 操作員 UI — 基礎語彙

原則：一眼判讀。同一顏色永遠代表同一意義，全站不混用。

語意色

OK 綠已綁定・在線・PASS
Warn 琥珀待處理・未綁定・警告
Error 紅MAC 不符・失敗・NG
Off 灰離線・空槽
Accent 靛主要動作・進行中

狀態 Chips（相機卡與面板共用）

已綁定 未綁定 MAC 不符 離線 取像中 mean 90.4 暗場 2.5

字級

28 / 700 — 關鍵數字（mean_gray、缺陷數）
18 / 700 — 頁面標題
14 / 400 — 內文與表單
12 / 400 muted — 輔助說明、SN/MAC
設計對應 Avalonia：色票進 Styles 資源字典；chips = 既有 Ellipse+TextBlock 樣式化； 不引入新框架，全部可用現有控制項實作。
