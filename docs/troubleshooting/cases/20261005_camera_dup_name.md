# 換相機後 CCD06 沒影像、CCD03 怪怪的 → 新相機被命名成 CCD03（撞名）

- 日期：2026-10-05　來源：實驗室故障注入（tools/triage/fault_inject.py、host_sudo_test.sh）　機台：user-IMB-M47 + spark-c16f + HPE 5945（借用機）
- 分類：camera　注入：{"mac": "00:30:53:54:e3:15"}　已還原：是（還原後健檢：正常）

## 線上人員看到的（原話）
剛換了一台相機（CCD06 的位置），換完之後 CCD06 沒有影像，而且 CCD03 的影像好像怪怪的。

## 證據：一鍵健檢結論
## 結論：❌ 1 項異常、⚠️ 0 項注意、✅ 6 項正常

1. ❌ **[相機] 有 2 台相機都叫 CCD03（身分衝突）**
   - 可能原因：換相機/設定時名稱寫錯，或複製了別台的設定 → Grab 會綁錯相機、另一個 CCD 變成「不見」
   - 請這樣做：用相機工具「裝置設定」把多出來的那台改回正確編號（MAC 對照基準，它應該是 CCD06）（設備工程）

（完整報告：`docs/troubleshooting/experiments/20261005_round2/dup_name.md`）

## 根因
兩台相機 DeviceUserID 都是 CCD03 → Grab 身分衝突、CCD06 等於消失

## 處置
1. 相機工具「裝置設定」把 MAC …e3:15 那台（基準是 CCD06）改回 CCD06
2. 重跑健檢；換相機後執行 --save-baseline

## 學到的 / 預防
健檢用 CCD↔MAC 基準反查「多出來那台原本是誰」，能直接說出該改回哪個編號

### 🔴 CCD06 沒有影像

**可能原因 [1][2][6]**：
- 新相機 CCD06 的網路線/光纖或交換機那端的模組鬆脫、損壞
- 新相機 CCD06 沒電（電源線/電源供應器）
- 交換機埠設定和基準不同（例如少了 speed 1000）
- 交換機有埠被手動關閉（shutdown）

**現場照做（設備工程）**：
1. 看 CCD06 相機背面燈號是否亮（不亮 = 沒電，查電源線）
2. 重插 CCD06 這條線兩端（相機端、交換機端模組）
3. 換一條線或交換機換一個空埠（埠位不必固定）
4. 若以上無效，請工程人員檢查交換機上 CCD06 插的埠設定（需 speed 1000、無 shutdown）

---

### 🔴 CCD03 影像「怪怪的」

從參考資料的紀錄來看，CCD03 在抓圖時出現了 **complete = 0.0%** 的狀況（即完全沒取到完整畫面），而其他相機正常 [8]。這表示 CCD03 的傳輸可能有問題。

**可能原因 [8]**：
- CCD03 的網路線/光纖鬆脫或損壞
- CCD03 相機本身故障或設定異常
- 交換機上 CCD03 的埠有異常

**現場照做（設備工程）**：
1. 重插 CCD03 的線（相機端、交換機端）
2. 換一條線或交換機換一個空埠
3. 檢查交換機上 CCD03 的埠設定（speed 1000）

<details><summary>助手 B 回答原文</summary>

## 結論

**CCD06 那台剛換上的相機，被設成和 CCD03 一樣的名稱（DeviceUserID 都為 CCD03），導致兩台相機身分衝突，grab 綁錯，CCD06 沒有影像、CCD03 影像異常。**

## 原因

健檢報告顯示：**兩台相機都叫 CCD03**【1】

| IP | MAC | 應為 |
|---|---|---|
| 192.168.5.3（MAC 00:30:53:54:e3:2b） | CCD03（正牌） |
| 192.168.5.6（MAC 00:30:53:54:e3:15） | 也被設成 CCD03，但它應該是 **CCD06** |

這表示換相機時，新相機的 **Device User ID** 被誤設為 `CCD03`（可能複製到舊 CCD03 的設定或打錯字），兩台同名 → Grab 拒開失敗或綁錯，CCD06 那台等於被「蓋掉」看不到【1】【6】。

## 現場照做（設備工程可做）

1. **先確認 grab 已停機**：在觸控螢幕或主機執行 `GRAB_STOP`，或先讓機台停機（不然 `cam_provision set` 會被擋）【6】。
2. **找出序號對應**：在 damac 主機（主電腦）執行：
   ```
   grab/build/cam_provision list
   ```
   找到 MAC `00:30:53:54:e3:15` 那一台的序號（SN）。
3. **把那台改回 CCD06**（一次設好名稱和 IP）：
   ```
   grab/build/cam_provision set <序號> CCD06
   ```
   工具會自動設 `DeviceUserID = CCD06` 和 `IP = 192.168.5.6`，如果名稱或 IP 撞到會拒絕【6】。
4. **ping 確認通**：
   ```
   ping 192.168.5.6
   ```
   確定有回應。
5. **重新開啟 grab**：`GRAB_START` 或重新開機台。

## 怎麼確認修好

- 再按一次「一鍵健檢」，**相機衝突項目應消失**。
- `LIST_CAMERAS` 應看到 **CCD03（MAC e3:2b）** 和 **CCD06（MAC e3:15）** 各自綁定正確【1】。
- CCD06 和 CCD03 的取像畫面都正常顯示。
