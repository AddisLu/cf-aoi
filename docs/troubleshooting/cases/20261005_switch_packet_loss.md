# CCD03 影像缺一截 → 交換機該埠最大框長 1536（jumbo 沒開）

- 日期：2026-10-05　來源：實驗室故障注入（tools/triage/fault_inject.py；RDMA 線斷為 rdma_cable_test.sh）　機台：user-IMB-M47 + spark-c16f + HPE 5945（借用機）
- 分類：switch　注入方式：CCD03 所插埠 jumboframe enable 1536（5945 不支援入方向限速，故改用此法）　已還原：是（還原後健檢：正常）

## 線上人員看到的（原話）
CCD03 的影像有時候缺一截、有黑色橫條，結果圖常判 NG，其他相機正常。

## 證據：一鍵健檢結論
## 結論：❌ 1 項異常、⚠️ 1 項注意、✅ 4 項正常

1. ❌ **[取像] CCD03 掉封包（影像不完整）**
   - 可能原因：交換機上 CCD03 所插的埠最大框長只有 1536（相機送 jumbo 封包需 ≥ 9000） → 大封包被丟。常見於換交換機/重置後 jumbo 沒開
   - 請這樣做：依原因處理：線材/模組問題 → 換標示「CCD03」的線或換交換機埠；限速/MTU 設定 → 找工程依基準設定還原；換完重跑健檢確認完整度 100%（設備工程）
2. ⚠️ **[交換機] 交換機設定和基準不同（1 行）**
   - 可能原因：有人改過交換機設定，或交換機更換/重置/升級後設定沒還原（例：相機埠少了 speed 1000 → 1G 相機永遠連不上）
   - 請這樣做：工程人員對照差異還原（相機埠需 speed 1000、上行 100G、jumbo），再 save force；換新交換機見 docs/troubleshooting_線上異常處理.md「交換機更換」（設備工程）

（完整報告：`docs/troubleshooting/experiments/20261005_fault_injection/packet_loss.md`、JSON：`packet_loss.triage.json`）

## 根因
相機送 jumbo 封包（約 8KB），埠最大框長 < 9000 → 被交換機丟棄（完整度 0%、超長封包 +11425）

## 處置
1. 工程把該埠最大框長設回（5945：jumboframe enable 9416）
2. 或先把標示 CCD03 的線改插其他埠
3. 重跑健檢確認完整度 100%

## 學到的 / 預防
健檢取像時同步讀交換機埠計數（giants/輸入錯誤/最大框長）才分得出「設定」與「線材」；只靠症狀助手會猜線材

## 機況助手表現（0–2 分）
- 只給症狀（A，舊知識庫）：**1** — 猜線材接觸不良（錯），沒有證據無法分辨
- 症狀 + 健檢報告（B，新知識庫）：**2** — 精準指出最大框長 1536 與修法

## 可能原因

1. **CCD03 到交換機之間的線材接觸不良**（RJ45 接頭鬆脫、線纜受損），造成傳輸 CRC 錯誤，`rdma_source` 會丟棄壞幀 [3]
2. **CCD03 掉線/瞬斷**（偶發離線），導致正在傳的 slice 沒到齊 [1]
3. **CCD03 MAC 位址對不上**（插錯交換機埠或更換過相機），系統會顯示「MAC 不符」而無法正常收圖 [1]

## 現場照做步驟（誰都可以做，建議通知設備／製程）

1. **檢查 CCD03 的網路線** — 拔起重插 CCD03 尾端的 RJ45 接頭（線材上有「CCD03」標示），交換機那一端的埠也要確認插緊。
2. **確認 LED／指示燈** — CCD03 的電源燈與連線燈是否恆亮；交換機對應埠的綠燈要閃爍正常。
3. **登入操作介面看 camera card 狀態**：
   - 若顯示 **「離線」** → 掉線，檢查電源與網路線。
   - 若顯示 **「MAC 不符」** → 插錯埠或換過相機未重新綁定，需要改接或按介面提示重新綁定 [1]。
   - 若顯示 **「未綁定」（琥珀色）** → 按介面指示一鍵綁定 [1]。
4. **查看 rdma-process 的 console log**，搜尋關鍵字 `[rdma-process] ⚠ 收圖遺失`，確認是否出現 `cam3`（CCD03）的 slice 遺失記錄 [6]。

## 怎麼確認修好

- 操作介面上 CCD03 的 card 顯示為正常狀態（卡上顯示「5 幀 · drop 0」、step 燈全亮）[1]
- 跑一片產品不再出現黑色橫條或 NG
- Console log 無 `[rdma-process] ⚠ 收圖遺失` 關於 cam3 的訊息 [6]

## 結論

**交換機上 CCD03 的埠（WGE1/0/39）最大框長被設成 1536**，相機送的 jumbo 封包（需 ≥ 9000）被交換機丟掉，導致 CCD03 影像缺一截、有黑色橫條、常被判 NG。【1】【3】

> 健檢報告直接指出：交換機該埠最大框長 1536（期間超長封包 +11425），完整度 0.0%。

---

## 可能原因

1. **有人手動改過交換機設定**：把 `jumboframe enable 9416` 改成 `jumboframe enable 1536`（健檢報告顯示交換機設定比基準多出這一行）。【1】
2. **交換機被重置或更換**：新交換機的預設值可能不是 9416，換上去後沒開 jumbo 就會這樣。【2】

---

## 現場照做步驟（誰可以做）

### 設備工程人員（需登入交換機權限）
1. 登入交換機，找到 CCD03 目前插的埠（現在是 **WGE1/0/39**，但線材上標示仍以 CCD03 為準）。
2. 下指令：
   ```
   interface WGE1/0/39
   jumboframe enable 9416
   quit
   save force
   ```
3. 回到 Control 畫面觀察 CCD03 是否恢復影像。

### 如果不會下交換機指令（現場作業員／線外人員）
1. **先把 CCD03 的網路線（線材上有 CCD03 標示）換插到另一個空埠**，看影像是否回來──如果回來，代表原埠的設定有問題，請通報設備工程處理。

---

## 怎麼確認修好

1. 在 Control 畫面看 CCD03 影像是否完整、不再缺一截或出現黑色橫條。
2. **重跑一鍵健檢**：確認 CCD03 的「完整度」回到 **100%**，且該埠不再報最大框長異常。

> ⚠️ 健檢報告還有一項：**交換機設定和基準不同（1 行）**，就是那行 `jumboframe enable 1536`，修完後要再跑一次健檢確認該行消失。
