# CCD02 偏暗 → 曝光被改成 10µs（設定 70µs）

- 日期：2026-10-05　來源：實驗室故障注入（tools/triage/fault_inject.py；RDMA 線斷為 rdma_cable_test.sh）　機台：user-IMB-M47 + spark-c16f + HPE 5945（借用機）
- 分類：camera　注入方式：CCD02 曝光 70→10 µs　已還原：是（還原後健檢：正常）

## 線上人員看到的（原話）
CCD02 的影像比其他台暗很多，缺陷數也變得很奇怪；昨天有人來調過機。

## 證據：一鍵健檢結論
## 結論：⚠️ 2 項注意、✅ 5 項正常（可生產，但請處理注意事項）

1. ⚠️ **[取像] CCD02 相機參數和設定不同：曝光 10.0 µs（設定 70.0）**
   - 可能原因：有人調過這台相機沒還原（相機工具 / pylon Viewer），影像會偏暗或偏亮、缺陷數異常
   - 請這樣做：Control 重新載入配方（Grab ARM 會套回設定值）；或用相機工具設回設定值（線上人員可先做）
2. ⚠️ **[交換機] 交換機設定和基準不同（1 行）**
   - 可能原因：有人改過交換機設定，或交換機更換/重置/升級後設定沒還原（例：相機埠少了 speed 1000 → 1G 相機永遠連不上）
   - 請這樣做：工程人員對照差異還原（相機埠需 speed 1000、上行 100G、jumbo），再 save force；換新交換機見 docs/troubleshooting_線上異常處理.md「交換機更換」（設備工程）

（完整報告：`docs/troubleshooting/experiments/20261005_fault_injection/param_drift.md`、JSON：`param_drift.triage.json`）

## 根因
調機後沒還原（相機工具 / pylon Viewer 改過），曝光與 cam_config.json 不同

## 處置
1. Control 重新載入配方（Grab ARM 套回設定值）
2. 或相機工具設回 70 µs
3. 重跑健檢確認無「參數和設定不同」

## 學到的 / 預防
健檢直接比對每台曝光/增益 vs 設定檔，不必等畫面變暗（實驗室無光源，亮度比對無法重現光學偏暗）

## 機況助手表現（0–2 分）
- 只給症狀（A，舊知識庫）：**1** — 方向對（有人調過），但叫線上人員改 LSC/config 檔，不適當
- 症狀 + 健檢報告（B，新知識庫）：**2** — 正確：重新載入配方即可

### 可能原因（依機率排序）

1. **昨天有人調過相機曝光參數**（光圈、曝光時間、增益）——這是最直接的原因，來調機的人可能動了 CCD02 的取像設定，導致平均亮度不足。
2. **光源強度衰減或光路偏移**——CCD02 對應的光源可能被調弱或偏離，造成整體亮度下降。
3. **Lens Shading（暗角）校正未正確啟用或參數跑掉**——如果昨天有人改了 config，可能把 CCD02 的 LSC 設定關掉或用了錯的係數 [2][5]。
4. **CCD02 本身老化或感光元件衰減**——較少見，但長期使用可能發生。

---

### 現場照做步驟（可由線上人員操作）

| 步驟 | 做什麼 | 誰可以做 |
|------|--------|----------|
| **①** | 叫出 CCD02 的即時影像畫面，查看平均亮度值（mean_brightness），正常應在 **60–180** 之間 [1]。 | 線上人員 |
| **②** | 檢查該影像的暗飽和比例（pct_zero），若 >10% 代表畫面太暗，會造成誤判缺陷 [1]。 | 線上人員 |
| **③** | 確認昨天調機的人是否改動了 CCD02 對應的 config 檔中的 LensShading 設定（特別檢查 `enable_lsc`、`lsc_k1/k2/k3` 是否與其他 CCD 一致）[5][6]。 | 線上人員 |
| **④** | 若亮度過低（mean < 60），先檢查 CCD02 的光圈環是否被轉動過，嘗試調回原位。 | 線上人員／請設備工程師 |
| **⑤** | 若光圈正常但仍偏暗，請機台工程師檢查 CCD02 對應的光源控制器（是否被調弱或關閉）。 | 請設備工程師 |
| **⑥** | 若上述都正常，有可能是 LSC 未啟用或係數跑掉，需將 config 中的 `enable_lsc = 1` 並檢查 `lsc_k1/k2/k3` 是否正確 [5][6]。 | 線上人員通知工程師修改 config |

---

### 如何確認修好

- **影像平均亮度**回到 60–180 之間 [1]。
- **暗飽和比例**（pct_zero）降到 10% 以下 [1]。
- **缺陷數**恢復與其他 CCD 相近的正常水準。
- 執行驗證腳本 `./build/t31_pylon_grab auto 500 8192 frame_ra_500.raw`，參考驗證報告 [3][4] 檢查亮度對比：光源打開後平均亮度應顯著提升（類似報告中 8.9→62.5 的變化）。
