# CCD05 沒影像 → 線路沒訊號（實驗：交換機埠被關閉）

- 日期：2026-10-05　來源：實驗室故障注入（tools/triage/fault_inject.py；RDMA 線斷為 rdma_cable_test.sh）　機台：user-IMB-M47 + spark-c16f + HPE 5945（借用機）
- 分類：camera　注入方式：交換機上 CCD05 所插的埠 shutdown　已還原：是（還原後健檢：正常）

## 線上人員看到的（原話）
Control 主畫面 CCD05 一直沒有影像，其他相機正常；產線停在等待取像。

## 證據：一鍵健檢結論
## 結論：❌ 2 項異常、⚠️ 1 項注意、✅ 4 項正常

1. ❌ **[相機] CCD05 不見了：線路沒有訊號**
   - 可能原因：CCD05 的網路線/光纖或交換機那端的模組鬆脫、損壞；或 CCD05 相機沒電（電源線/電源供應器）
   - 請這樣做：請找線材標示「CCD05」的那一條：① 看 CCD05 相機背面燈號是否亮（不亮 = 沒電，查電源線）② 重插這條線兩端（相機端、交換機端模組） ③ 換一條線或交換機換一個空埠（埠位不必固定）（設備工程）
2. ❌ **[交換機] 交換機設定和基準不同（1 行）—很可能就是 CCD05 不見的原因**
   - 可能原因：有人改過交換機設定，或交換機更換/重置/升級後設定沒還原（例：相機埠少了 speed 1000 → 1G 相機永遠連不上）
   - 請這樣做：工程人員對照差異還原（相機埠需 speed 1000、上行 100G、jumbo），再 save force；換新交換機見 docs/troubleshooting_線上異常處理.md「交換機更換」（設備工程）
3. ⚠️ **[交換機] 交換機有埠被手動關閉（shutdown）：WGE1/0/35**
   - 可能原因：有人下了 shutdown，或換交換機後設定不同 → 相機插在這些埠會沒有訊號
   - 請這樣做：相機改插其他埠；或工程人員 undo shutdown（設備工程）

（完整報告：`docs/troubleshooting/experiments/20261005_fault_injection/cam_missing.md`、JSON：`cam_missing.triage.json`）

## 根因
交換機埠被手動關閉 → 該 CCD 線路沒有訊號（現場同類：線鬆脫、模組壞、相機沒電）

## 處置
1. 看標示 CCD05 的線材兩端與相機燈號
2. 交換機埠被關閉 → 工程 undo shutdown，或改插其他空埠（埠位不必固定）
3. 重跑一鍵健檢確認 CCD05 出現

## 學到的 / 預防
健檢用 CCD↔MAC 判斷「線路沒訊號」vs「有訊號沒回應」；交換機 ADM 狀態與設定差異直接指出被關閉

### 可能原因（依常見度排序）

1. **CCD05 掉線/離線** — 電源或網路線接觸不良、交換機埠鬆脫，使相機未被主機偵測到 [2][3]
2. **CCD05 網路線插錯交換機埠** — MAC 位置與綁定紀錄不符，系統已標示「MAC 不符」並擋下取像 [2]
3. **CCD05 偵測到但未綁定** — 相機硬體有通電，但尚未在系統綁定（UI 會顯示琥珀色警告卡）[2]
4. **交換機該埠故障** — 交換機該埠硬體異常，無法與 CCD05 通訊
5. **CCD05 本身硬體異常** — 相機故障或供電不足

## 可能原因

1. **有人對交換機下了 `shutdown` 指令**，把 WGE1/0/35 關閉了 [1] – 這是健檢報告明確指出的。
2. **更換交換機或重置後，設定沒還原** – 新交換機可能沒設 `speed 1000`，或舊設定裡有 `shutdown` 被帶過來 [4][7]。
3. **CCD05 那條網路線/光纖或模組**雖然插著有訊號，但因為交換機埠被關閉，根本不會傳資料。

> CCD05 相機本身有 MAC 00:30:53:54:e3:16 在記錄裡但不在交換機表上，和「埠被 shutdown」完全吻合 [2]。

## 現場照做步驟（誰可以做）

### 👷 設備工程人員

**① 檢查交換機上 WGE1/0/35 的狀態**
用 console 登入交換機（damac `/dev/ttyUSB0`，9600 8N1），下指令：
```
display interface Twenty-FiveGigE1/0/35
```
如果看到 `shutdown`，就是被關閉了。

**② 把 WGE1/0/35 打開並設正確速度**
```
interface Twenty-FiveGigE1/0/35
undo shutdown
speed 1000
quit
save force
```
> 注意：`speed 1000` 有 port-group 連動（35 和 33–36 同一組），下指令後要記得回 `Y` 確認 [4][7]。

**③ 或用最快方式：CCD05 線改插到其他沒 shutdown 的 WGE 埠**
（5945 交換機全部 WGE 埠已預設 `speed 1000` + `stp edged-port`，插上去就會 UP）[4][7]

### 👷 設備工程人員（選項二）

如果只是要趕快復線，**CCD05 那條線改插到另一個 WGE 空埠**（例如 WGE1/0/36），不必改交換機設定，也不用重配 IP——CCD 是依 MAC 綁定的，插到不同埠也能用。

---

## 怎麼確認修好

1. **看交換機埠燈號**：WGE1/0/35（或新插的埠）的 Link/ACT 燈要亮。
2. **下指令檢查**：
   ```
   display interface brief | include WGE1/0/35
   ```
   看到 `UP 1G` 表示正常 [4]。
3. **回 Control 主畫面看 CCD05**：如果影像出現了、不再卡「等待取像」，就修好了。
4. **重新跑一次一鍵健檢**：確認相機和交換機的異常都消失。
