# Constitution — C++（不隨任務變的 house rules）

## 註解與語言
- 所有新增/修改的註解一律使用繁體中文。

## 風格與慣例
- 跟隨檔案既有風格（命名、縮排、include 順序），不得引入新風格。
- 資源管理一律 RAII；不得裸 `new`/`delete`。
- 錯誤處理遵循該模組既有慣例（回傳碼或例外，二者不得混用）。

## 邊界與安全
- 所有外部輸入（影像尺寸、設定值、recipe 參數）必須驗證後才使用。
- 多執行緒共享狀態必須沿用既有的鎖/原子慣例，不得新增全域可變狀態。

## 禁止事項
- 不得改動公開介面/ABI（標頭中的函式簽名、struct 佈局），除非 spec 明示。
- 不得新增第三方依賴。
- 不得順手重構 spec 範圍外的程式碼。
